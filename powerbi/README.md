# Power BI Assets

- `PowerBI_Dashboard_Guide.md`: report pages, model setup, visuals, interactions, and validation targets.
- `measures.dax`: date table and reusable measures.
- `theme.json`: importable Power BI report theme.

Power BI Desktop is required to save the final `.pbix` report. The source data and report definition assets are kept separate so the workbook can be refreshed without editing the report design.
